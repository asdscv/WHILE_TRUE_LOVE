# 인쇄용 안내 카드

결혼식 당일 테이블에 놓고 나눠줄 식사 장소 안내 카드입니다.

| 파일 | 용도 |
| --- | --- |
| `meal-notice.html` | A4 한 장에 같은 카드 4개(2×2). 브라우저로 열어 바로 인쇄 |

- 내용: 식사 장소(유담헌)가 예식장(백인제가옥)과 다르다는 안내 + 이름·주소·전화 +
  네이버지도로 연결되는 QR 코드.
- 인쇄 방법: `meal-notice.html` 을 브라우저로 열고 Cmd+P → 용지 A4, 배율 100%(맞춤 아님),
  여백 없음으로 설정 후 인쇄. 가운데 점선을 따라 가위로 자르면 카드 4장이 나옵니다.
- 색 없이 검정 텍스트 + 흰 배경만 써서 흑백 프린터로 인쇄해도 선명합니다.
- QR 은 `design/qr/meal-yudamheon.svg` 와 같은 내용을 인라인으로 담고 있습니다
  (네이버 장소 고유 링크 `https://map.naver.com/p/entry/place/1936370536`, 오류정정 H).

## 주의

- `meal-notice.html` 은 Vite 빌드에 포함되지 않는 독립 파일이라
  `src/config.js` 의 `config.location.meal` 과 자동으로 동기화되지 않습니다.
  식당 정보(이름·주소·전화)가 바뀌면 두 곳을 각각 고쳐야 합니다.
- QR 주소가 바뀌면 `design/qr/README.md` 의 방법대로 다시 만들고,
  `meal-notice.html` 안의 4곳(카드마다 하나씩) SVG 를 모두 같은 내용으로 바꿔주세요.
